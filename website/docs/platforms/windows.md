# MoldSign alternative for Windows — electronic signatures

**eSemnBun is an independent MoldSign alternative for Windows.** Sign PDFs with a supported Moldovan electronic identity card and USB reader, verify files, and connect compatible websites through the local browser bridge. Choose the desktop installer for the graphical app or the separate [Windows CLI and MCP tools](./windows-cli.md) for terminal and agent setup. eSemnBun is not affiliated with STISC.

Choose what you want to do. Each task has its own short illustrated guide.

## Before you begin

Applies to **eSemnBun 0.2.13**, Windows 10 **1809 or later**, and Windows 11. See the [Windows CLI guide](/docs/platforms/windows-cli/) for PowerShell and automation workflows.
