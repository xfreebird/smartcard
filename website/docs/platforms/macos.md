# MoldSign alternative for Mac — electronic signatures on macOS

**eSemnBun is an independent MoldSign alternative for Mac (macOS).** Use a supported Moldovan electronic ID and USB reader to sign PDFs, create XAdES signatures and verify documents. Both the standalone DMG and Mac App Store edition detect compatible USB readers and cards and support the built-in browser and compatible external browsers. [CLI and MCP tools](./macos-cli.md) are installed separately; a Homebrew CLI package is not the desktop app. eSemnBun is not affiliated with STISC.

Choose what you want to do. Each task has its own short illustrated guide.
