# iPhone and iPad

Current documentation version: **0.2.0**.

Install eSemnBun through Apple's distribution channels. On iPhone, connect the compatible reader through the appropriate USB-C or Lightning adapter. On iPad and iPhone Duo, the app uses the extra space for document and file-browser operations.

<PlatformScreenshots platform="ios" alt="eSemnBun for iPhone and iPad" />

## Sign, share, and verify

Open files from eSemnBun or share a document from another app to the eSemnBun share extension. Select the card, check the document list, and enter the PIN when asked. Finished documents can be shared from the result controls.

The app keeps the selected card centred in a swipeable card carousel. When several documents use the same card in one batch, the signing flow can reuse its approved session PIN for that batch.

## Browser services

iOS provides an in-app browser because external browsers cannot expose all required card workflows. Use its address field, navigation controls, bookmarks, and reset controls. You can add, edit, remove, and choose an icon for personal bookmarks. For sites that hide identity login on mobile, the browser can request the desktop presentation for that login flow.

The iOS app refers only to the mobile device connection. NFC is not supported.
