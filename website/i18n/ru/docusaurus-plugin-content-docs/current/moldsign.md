# Электронная подпись с ID-картой: альтернатива MoldSign

**eSemnBun** — бесплатное приложение с открытым кодом для подписи документов совместимой электронной ID-картой Республики Молдова. Оно работает на компьютере и телефоне с подходящим USB-считывателем.

По-румынски этот способ называется **semnătură electronică cu cartea de identitate**. Вы подтверждаете операцию PIN-кодом, а закрытый ключ подписи остаётся на карте.

Подпись связывает документ с сертификатом подписанта и позволяет обнаружить изменения подписанного содержимого. Изображение рукописной подписи или видимый штамп в PDF сами по себе не обеспечивают такую криптографическую проверку. Подробнее — в [руководстве по подписи и проверке](./signing.md).

## Выберите альтернативу MoldSign для своего устройства

- [Альтернатива MoldSign для Windows](./platforms/windows.md): настольная установка, USB-считыватель и подключение браузера.
- [Альтернатива MoldSign для Mac](./platforms/macos.md): версии DMG и Mac App Store с отдельными инструментами CLI.
- [Альтернатива MoldSign для Linux](./platforms/linux.md): приложение GNOME, настройка PC/SC и командная строка.
- [MoldSign MCP для ИИ-агентов](./mcp-moldsign.md): локальная проверка и явно настроенная подпись PDF на Windows, Mac и Linux.

Выберите версию на странице [загрузок](/downloads/). Руководство платформы описывает требования и доступные функции.

## MoldSign, MSign и eSemnBun: в чём разница?

| Название | Назначение |
| --- | --- |
| MoldSign | Программный комплект поставщика: настольное приложение и локальный сервер подписи |
| MSign | Сервис подписи на [msign.gov.md](https://msign.gov.md/#/) |
| eSemnBun | Независимое приложение для подписи файлов и совместимых локальных запросов |

Разработчик eSemnBun — Nicolae Ghimbovschi. Проект не связан со STISC, не выдаёт сертификаты и не активирует ID-карты. Приём документов зависит от требований конкретного сервиса.

## Что понадобится?

- Поддерживаемая электронная ID-карта с действующим сертификатом подписи.
- Правильный PIN-код этой карты.
- Совместимый USB-считыватель, например bit4id miniLector POCKET EVO.
- Подходящий адаптер для компьютера, iPhone, iPad или Android.
- Интернет для меток времени и онлайн-служб доверия.

Начиная с eSemnBun 0.2.12, совместимые iPhone и Android поддерживают подпись по NFC с совместимым бесконтактным удостоверением. Можно также использовать совместимый USB-считыватель. Для NFC и USB нужны действующий сертификат подписи и PIN-код карты.

## Как подписать PDF электронной ID-картой

1. Установите eSemnBun для своего устройства и откройте приложение.
2. Выберите NFC или USB-считыватель на экране **Подписать**. Для NFC следуйте подсказке сканирования после подтверждения PIN-кода. Для USB подключите считыватель, вставьте карту и проверьте выбранного владельца.
3. Проверьте владельца, срок действия и выбранную карту.
4. Добавьте PDF и выберите **PAdES-T**, чтобы встроить подпись в PDF.
5. Проверьте запрос и подтвердите подпись PIN-кодом.
6. Сохраните или отправьте результат. Откройте **Проверить**, чтобы изучить подпись.

Можно подтвердить список документов одним пакетом. Для отсоединённой XAdES сохраняйте оригинал вместе с XML-подписью. Подробнее — в [руководстве по подписи и проверке](./signing.md).

## На компьютере и телефоне

Версия macOS с GitHub подписана, нотаризована и устанавливается из DMG. Версия Mac App Store использует рабочий процесс с учётом ограничений системы. Для Windows доступен MSI, для Linux — настольное приложение и CLI.

Приложения iPhone, iPad и Android позволяют подписывать с помощью USB-считывателя и адаптера и отправлять готовые файлы. Встроенный браузер помогает, если сайт скрывает вход по ID-карте в мобильной версии. Выберите [руководство для своей платформы](/docs/platforms).

Это подпись **ID-картой на телефоне**, а не мобильная подпись через SIM оператора. eSemnBun не подключает услугу SIM-подписи.

## MSign и совместимые сайты

Для настольного браузера включите локальное подключение и оставьте eSemnBun запущенным на том же компьютере. На телефоне или в версии Mac с ограниченным доступом используйте предлагаемый встроенный браузер. Перед подтверждением проверяйте адрес сайта и операцию.

Если MoldSign Server уже занимает локальные порты, устраните конфликт до включения сервера eSemnBun. См. [работу с государственными сервисами](./browser.md).

## Частые вопросы

### Подойдёт любая ID-карта?

Нет. Нужна поддерживаемая карта с действующим сертификатом подписи, подходящим считывателем и правильным PIN-кодом. Приложение не выдаёт и не активирует карты.

### Можно подписать без считывателя?

Начиная с eSemnBun 0.2.12, совместимые iPhone и Android поддерживают подпись по NFC с совместимым бесконтактным удостоверением. Можно также использовать совместимый USB-считыватель. Для NFC и USB нужны действующий сертификат подписи и PIN-код карты.

### Как проверить электронную подпись?

Выберите PDF или XML в разделе **Проверить**. Для отсоединённой XAdES также укажите оригинал. Изучите целостность документа, подпись и информацию сертификата. Офлайн-проверка сама по себе не устанавливает текущее состояние отзыва сертификата.

### Что делать при неверном PIN?

Остановитесь и проверьте выбранную карту и PIN-код. Повторные неверные попытки могут заблокировать карту. См. [устранение проблем](./troubleshooting.md).
