# Подпись и проверка документов

1. Добавьте документы через выбор файлов или перетаскивание.
2. Проверьте выбранную карту и формат каждого файла.
3. Нажмите **Подписать**, проверьте запрос и введите правильный PIN-код.
4. Сохраните, экспортируйте или отправьте результат.

PAdES сохраняет подпись внутри PDF. XAdES создаёт XML-подпись; сохраняйте исходный документ рядом с отделённой подписью. Пакетная подпись позволяет подтвердить список документов вместе. PIN-код сессии ограничен текущей операцией подписи.

Закрытый ключ остаётся на карте. Для меток времени и онлайн-проверки сертификатов может потребоваться интернет.

## Выберите способ подписи

Начиная с eSemnBun 0.2.12, на совместимом iPhone или Android-устройстве можно подписывать документы с совместимой бесконтактной картой по NFC. Можно также использовать совместимый USB-считыватель.

На экране **Подписать** выберите **С телефона · NFC** и добавьте документ. Нажмите **Продолжить**, проверьте запрос и подтвердите PIN-код подписи. Держите карту возле NFC-антенны телефона до сообщения о завершении. На Android включите NFC.

Для USB подключите считыватель через подходящий [адаптер](/devices), выберите **Со считывателем карт** на экране **Подписать** и вставьте карту. Если подключено несколько карт, выберите нужного владельца перед продолжением.

## Проверка

Откройте **Проверить** и выберите подписанный PDF или XAdES. Можно использовать перетаскивание. Технический результат проверки не гарантирует принятие документа любым получателем.

## Сохранённые PIN-коды

Управляйте ими на отдельной вкладке настроек. Защита и подтверждение зависят от платформы. Удаляйте сохранённые PIN-коды, когда они больше не нужны.
