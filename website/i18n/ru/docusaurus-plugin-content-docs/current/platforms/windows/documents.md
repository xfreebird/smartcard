Откройте сведения о подписи, отправьте файлы и очистите историю.

## Найдите и откройте сохранённые документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Выберите имя файла, чтобы посмотреть сведения о подписи. Кнопки в его строке открывают файл и показывают его папку. В меню строки доступны проверка и защита файла. В истории перечислены недавние операции. При очистке истории сохранённые файлы сохраняются.
