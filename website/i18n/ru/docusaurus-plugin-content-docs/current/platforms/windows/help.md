# Решите проблему — Справочник Windows для компьютера

[Все руководства платформы](../windows.md) · [Установка и подключение считывателя](./setup.md)

Безопасно решайте проблемы считывателя, PIN, документов и соединения.

## Обновите приложение или устраните проблему

Установки Microsoft Store обновляются через магазин. Самостоятельные сборки предлагают проверку обновлений с переходом на страницу загрузки; установите новый MSI выпуска.

| Симптом | Следующий шаг |
| --- | --- |
| Считыватель отсутствует | Найдите считыватель смарт-карт в Диспетчере устройств; переподключите его и проверьте службу Smart Card. |
| Сертификат не загружается | Вставьте карту заново и дождитесь окончания чтения. |
| Выбрана другая личность | Выберите нужную карту перед вводом её PIN. |
| Порт браузера занят | Остановите распознанный конкурирующий сервер, затем подключитесь снова. |
| Сохранённый PIN недоступен | Введите PIN вручную и проверьте аутентификацию/настройки Windows. |
| Ошибка документа | Изучите ошибку, сохраните исходник и устраните причину перед повтором. |

После неверного PIN остановитесь и проверьте его, не пытайтесь угадывать. Сообщите версии приложения и Windows, редакцию MSI или Store, архитектуру, модель считывателя и шаги воспроизведения. См. [устранение неполадок](/docs/troubleshooting).
