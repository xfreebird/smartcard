Поделитесь сертификатом шифрования

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Поделитесь сертификатом шифрования

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Подключите поддерживаемую карту и USB-считыватель. Для экспорта открытого сертификата не нужны документ или PIN. Карта должна предоставлять идентичность шифрования; обычный сертификат подписи её не заменяет.

После чтения выберите нужную идентичность и раскройте сведения о сертификате. Экспортируйте сертификат шифрования, сохраните .cer и передайте отправителю. Отдельно сравните отпечаток. Экспортируется только открытый сертификат; закрытый ключ остаётся на карте. На снимке показан начальный экран до чтения.
