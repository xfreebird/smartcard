# Найдите сохранённые документы — iPad

[Все руководства платформы](../ipad.md) · [Установка и подключение считывателя](./setup.md)

Откройте сведения о подписи, отправьте файлы и очистите историю.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Найдите документ и откройте сведения о подписи

Откройте Документы и выберите сохранённый элемент. Модальное окно сведений использует ту же проверку, что вкладка Проверка, и не заменяет её текущие файлы. Просмотр открывает содержимое, Поделиться экспортирует выбранный файл. Перемещённый или нечитаемый файл выберите снова из его фактического расположения.

## Очистите историю, сохранив документы

В Документах перейдите в Историю, выберите очистку списка и подтвердите. Удаляется список недавних операций, а не подписанные файлы или коллекция Документов. Вернитесь в Документы для сохранённых результатов. Экспортированный файл удаляется в Файлах или его хранилище.
