# Начало работы — iPad

[Все руководства платформы](../ipad.md)

Установите приложение, подключите считыватель и выберите карту.



## Подключите считыватель и вставьте карту

Понадобится действующее молдавское электронное удостоверение личности с сертификатом подписи и PIN-кодом подписи.

### Подпишите через USB-считыватель

Для USB подключите считыватель через подходящий [адаптер](/devices), выберите **Со считывателем карт** на экране **Подписать** и вставьте карту. Если подключено несколько карт, выберите нужного владельца перед продолжением.

<GuideScreenshot src="/img/guide/ipad/ru/reader-sign.png" alt="Экран подписания с выбранным USB-считывателем" steps={[{"text": "Экран подписания с выбранным USB-считывателем"}]} />

## Выберите владельца подписи

Чтобы посмотреть подключённую карту, откройте **Настройки → Карты и считыватели**. Кнопка информации в правом верхнем углу экрана подписания открывает сведения о карте. Для управления PIN-кодами откройте **Настройки → Сохранённые PIN-коды**.

## Используйте окна iPad и Файлы рядом с подписанием

Здесь используются родные снимки iPad, а не увеличенные изображения телефона. Интерфейс следует ширине окна. В широком окне карта и файловые действия могут оставаться рядом; в узком навигация компактнее. Откройте Файлы рядом с eSemnBun и выбирайте или перетаскивайте документы там, где это разрешает система. Увеличьте окно или прокрутите, если действие скрыто. Для запроса сайта приложение должно быть активно. Снимки показывают родное портретное окно, а не проверку всех жестов многозадачности.
