# Измените настройки — iPad

[Все руководства платформы](../ipad.md) · [Установка и подключение считывателя](./setup.md)

Настройте язык, оформление, сохранённые PIN, запуск и обновления.

## Измените язык, оформление и приватность

Откройте Карту, затем Настройки. Выберите Română, English, Русский или системный язык, светлую, тёмную или системную тему. Включайте PDF-штампы браузера только при необходимости для поддерживаемых запросов сайта. Обычный демонстрационный режим намеренно помечен и не создаёт реальных подписей. Раздел О приложении показывает версию и справочные данные. Обновления приходят через канал Apple, использованный при установке.

Для сохранённого PIN откройте Карту нужного владельца и удалите сохранённый PIN, если действие доступно. Сохранение использует защищённое хранилище платформы и аутентификацию устройства; удаление копии не меняет и не разблокирует физический PIN. Другой карте нужен собственный PIN.
