# Начало работы — Mac · Командная строка (CLI)

[Все руководства платформы](../macos-cli.md)

Установите приложение, подключите считыватель и выберите карту.

## Установите и проверьте доступные возможности

Откройте [Загрузки](/downloads/) и выберите платформу. Архивы CLI содержат терминальные инструменты и MCP; приложение для рабочего стола устанавливается отдельно. Используйте инструкции менеджера пакетов с актуальной версией и отпечатком ключа. Найдите команду и проверьте возможности перед автоматизацией.

<GuideScreenshot src="/img/guide/macos-cli/ru/install.svg" alt="1. Установите и проверьте доступные возможности" caption="Учебный пример команды. Скопируйте команды ниже, заменив пути и имя считывателя." steps={[{"x": 3, "y": 23.8, "text": "Установите через выбранный канал платформы."}, {"x": 3, "y": 83.2, "text": "Проверьте возможности перед обращением к карте."}]} />

```sh
brew install xfreebird/utils/esemnbun-cli
command -v esemnbun
esemnbun capabilities --json
```

<GuideScreenshot src="/img/guide/macos-cli/ru/capability.svg" alt="руководство командной строки" caption="Локальный результат возможностей без доступа к карте." steps={[{"x": 3, "y": 5.1, "text": "Проверьте возможности перед обращением к карте."}]} />

```sh
esemnbun capabilities --json
```

Локальная сборка сообщает недоступность MCP в обычном CLI; отдельный esemnbun-mcp имеет собственное обнаружение. Проверяйте установленные программы.

## Найдите считыватель и проверьте сертификат

Подключите USB-считыватель и вставьте карту. Выведите считыватели, затем прочитайте сертификат без PIN. При нескольких картах укажите точное имя считывателя и проверьте владельца перед подписью. Это учебные команды; считыватель для руководства не использовался.

<GuideScreenshot src="/img/guide/macos-cli/ru/reader.svg" alt="2. Найдите считыватель и проверьте сертификат" caption="Учебный пример команды. Скопируйте команды ниже, заменив пути и имя считывателя." steps={[{"x": 3, "y": 23.8, "text": "Выведите считыватели и наличие карт."}, {"x": 3, "y": 53.5, "text": "Прочитайте нужный сертификат; замените имя считывателя."}, {"x": 3, "y": 83.2, "text": "Вычислите SHA-256 экспортированного сертификата. Для подписи без присутствия используйте эти 64 шестнадцатеричные цифры, а не SHA-1 из cert."}]} />

```sh
esemnbun readers
esemnbun cert --reader "miniLector EVO" --out leaf.der
shasum -a 256 leaf.der
```
