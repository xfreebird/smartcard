# Удалите локальный файл — Mac · Командная строка (CLI)

[Все руководства платформы](../macos-cli.md) · [Установка и подключение считывателя](./setup.md)

Удалите локальный файл

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Удалите локальный файл

Только на компьютере. После подтверждения безвозвратно удаляется один поддерживаемый обычный локальный файл. Стирание с SSD, снимков, резервных и других копий не гарантируется. Неподдерживаемые расположения и ссылки отклоняются. Мобильные поставщики документов не поддерживают операцию.

Учебный пример команды — операция не выполнялась.

```sh
esemnbun remove-file disposable-copy.pdf --confirm-removal
```
