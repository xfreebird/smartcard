# Проверьте подпись — Mac · Командная строка (CLI)

[Все руководства платформы](../macos-cli.md) · [Установка и подключение считывателя](./setup.md)

Проверьте PDF или XML, сведения о подписанте и сертификате.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Проверьте документ и результат

Выберите подписанный PDF/XML. Для отделённого XML укажите папку с неизменными оригиналами. Проверка автономная: целостность, подпись и встроенная цепочка не устанавливают текущий статус отзыва. `ok:true` означает успешное выполнение, а не действительность подписи. Отсутствие распознанных подписей не означает успешную проверку подписанного документа.

```sh
esemnbun verify Contract-semnat.pdf
esemnbun verify Declaration.xml /home/me/Originals
esemnbun verify --json Contract-semnat.pdf
```

<GuideScreenshot src="/img/guide/macos-cli/ru/unsigned.svg" alt="руководство командной строки" caption="Локальный результат без обращения к карте; вымышленный файл не содержит подписей." steps={[{"x": 3, "y": 16.7, "text": "Для автоматизации анализируйте status JSON, а не только ok."}]} />

```sh
esemnbun verify --json unsigned.pdf
```

`valid` и `unconfirmed` дают код0; второй оставляет доверие неподтверждённым. `invalid`, `incomplete`, `no_recognized_signature` дают код2. Отсутствие оригиналов означает неполноту, а не доказанное изменение. Код1: ввод/использование; 3: неверный PIN; 4: PIN заблокирован; 5: нет карты/считывателя; 6: ошибка сети служб доверия. После ошибки PIN остановитесь. Приложение не разблокирует карту.
