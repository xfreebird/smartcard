## Зашифруйте для владельца сертификата

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Попросите у получателя открытый сертификат шифрования (.cer/.der), экспортированный по следующему руководству. Подтвердите отпечаток с владельцем по доверенному каналу. Сертификата только для подписи недостаточно. Для шифрования нужен открытый сертификат, а не карта, закрытый ключ или PIN получателя.
