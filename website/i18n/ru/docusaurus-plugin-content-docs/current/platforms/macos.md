# Альтернатива MoldSign для Mac — электронная подпись на macOS

**eSemnBun — независимая альтернатива MoldSign для Mac (macOS).** Подписывайте PDF, создавайте XAdES и проверяйте документы с поддерживаемой ID-картой Молдовы и USB-считывателем. DMG и версия Mac App Store обнаруживают совместимые USB-считыватели и карты и поддерживают встроенный браузер и совместимые внешние браузеры. [Инструменты CLI и MCP](./macos-cli.md) устанавливаются отдельно; CLI-пакет Homebrew не является настольным приложением. eSemnBun не связан со STISC.

Выберите задачу. Для каждой есть отдельное краткое иллюстрированное руководство.
