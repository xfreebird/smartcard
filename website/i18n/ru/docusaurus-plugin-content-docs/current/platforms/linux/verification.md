# Проверьте подпись — Linux

[Все руководства платформы](../linux.md) · [Установка и подключение считывателя](./setup.md)

Проверьте PDF или XML, сведения о подписанте и сертификате.

## Проверьте PDF

Проверка не требует карты или PIN. Откройте Проверить и выберите/перетащите подписанный PDF/XML. Поддерживается несколько файлов. Читайте каждую подпись, а не полагайтесь на имя или штамп. Офлайн-проверка не устанавливает текущий статус отзыва сертификата.

## Изучите сертификат и технические данные

Прокрутите результат и раскройте сведения о сертификате и технические данные. Целостность, криптографическая подпись, доверие и отметка времени — отдельные проверки. Сведения организации-издателя не являются личным идентификатором подписанта.

## Проверьте отделённый XML с оригиналом

Для отделённого XAdES положите точный неизменённый оригинал рядом с XML под именем из ссылки подписи, затем снова выберите XML в Проверить. В Linux пока нет встроенного выбора оригиналов: связь разрешается из папки XML. Отсутствующий оригинал не позволяет полностью проверить целостность.
