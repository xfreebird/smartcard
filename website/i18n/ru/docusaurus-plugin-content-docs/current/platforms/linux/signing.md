# Подпишите документы — Linux

[Все руководства платформы](../linux.md) · [Установка и подключение считывателя](./setup.md)

Добавьте файлы, выберите формат и штамп, подтвердите и сохраните результат.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Добавьте документы пакета

Выберите или перетащите все нужные файлы в Подписать. Можно выбрать несколько документов. Проверьте имена и удалите лишнее до разрешения. Перетаскивание зависит от файлового менеджера; выбор файлов остаётся доступным.

## Выберите формат подписи

Подпись PDF — PAdES-T внутри PDF. Подпись XML — XAdES-BES; XML с отметкой времени — XAdES-T; XML с данными проверки — XAdES-C. Отметки времени и данные статуса требуют соответствующих сетевых служб. Сохраняйте отделённый XML с неизменённым оригиналом.

<GuideScreenshot src="/img/guide/linux/ru/format.png" alt="Выберите формат подписи" steps={[{"text": "Откройте меню с тремя точками.", "x": 74, "y": 49}, {"text": "Выберите нужный получателю формат.", "x": 72, "y": 67}, {"text": "Удалите лишний файл из того же меню.", "x": 73, "y": 87}]} />

## Разместите необязательный PDF-штамп

Откройте меню файла и добавьте штамп. Видимый штамп необязателен и не заменяет криптографическую подпись. Не закрывайте важный текст. Пример PDF явно помечен как неподписанный.

<GuideScreenshot src="/img/guide/linux/ru/stamp.png" alt="Разместите необязательный PDF-штамп" steps={[{"text": "Включите штамп и выберите страницы.", "x": 79, "y": 23}, {"text": "Перетащите/измените размер в просмотре PDF.", "x": 22, "y": 53}, {"text": "Примените размещение либо отмените изменение.", "x": 80, "y": 83}]} />

## Проверьте и разрешите пакет

Используйте PIN подписи выбранной карты, а не пароль Linux. Проверьте владельца и весь список. Новый пакет требует нового разрешения. После неверного PIN остановитесь и уточните его: повторные догадки могут заблокировать карту. Диалог примера не обращается к настоящему хранилищу и отключает сохранение.

<GuideScreenshot src="/img/guide/linux/ru/pin.png" alt="Проверьте и разрешите пакет" steps={[{"text": "Проверьте владельца и имена файлов.", "x": 50, "y": 40}, {"text": "Введите PIN в защищённом поле.", "x": 50, "y": 54}, {"text": "Нажмите Подписать; отмените неожиданный запрос.", "x": 61, "y": 66}]} />

## Дождитесь подписи и отметки времени

Оставьте считыватель подключённым до результата. Отметка времени требует сети. Сетевая ошибка отличается от неверного PIN; прочитайте сообщение до нового осознанного запроса.

<GuideScreenshot src="/img/guide/linux/ru/progress.png" alt="Дождитесь подписи и отметки времени" steps={[{"text": "Дождитесь текущих этапов и окончательного результата.", "x": 57, "y": 86}]} />

## Найдите готовый файл

Приложение создаёт отдельный результат, сохраняя исходник. Откройте готовую строку для просмотра/поиска файла. Сохраняйте оригинал с отделённым XML. Показанное завершение относится к вымышленному неподписанному примеру.

<GuideScreenshot src="/img/guide/linux/ru/success.png" alt="Найдите готовый файл" steps={[{"text": "Откройте готовую строку для просмотра/поиска файла.", "x": 70, "y": 48}]} />

## Разберитесь с ошибкой файла

В пакете могут быть готовые файлы и ошибки. Сохраните готовое, прочитайте сообщение и исправьте причину до нового запроса. Автоматического повтора PIN и исправления повреждённых файлов нет.
