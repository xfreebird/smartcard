## Зашифруйте файл паролем

Откройте главное меню в заголовке окна, затем **Защита файлов → Зашифровать**, **Расшифровать** или **Удалить файл**. Выберите доступный файл; при необходимости прокрутите форму.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

Выберите **Пароль** и укажите AES-128, AES-192 или AES-256. По умолчанию используется AES-256. Чтобы зашифровать файл для получателя, выберите **Сертификат RSA** и укажите его открытый сертификат шифрования (.cer или .der). По умолчанию используйте сертификат шифрования. **Совместимость с открытым ключом карты** явно разрешает открытый ключ RSA карты. Успешный экспорт или шифрование не доказывают возможность расшифровки: соответствующая карта должна поддерживать нужную операцию с закрытым ключом.

Нажмите **Зашифровать** или **Расшифровать**, затем **Сохранить копию** и выберите новое расположение результата. После сохранения файл появится в **Документы → Сохранённые документы**. По завершении нажмите кнопку закрытия в заголовке окна. Оригинал сохраняется.

Сохранённые документы включают подписанные, зашифрованные и расшифрованные файлы. Определяйте результат по имени файла и метке операции. Шифрование не создаёт цифровую подпись; перед открытием или проверкой содержимого зашифрованный файл нужно расшифровать.
