# Измените настройки — Linux

[Все руководства платформы](../linux.md) · [Установка и подключение считывателя](./setup.md)

Настройте язык, оформление, сохранённые PIN, запуск и обновления.

## Выберите язык и оформление

Откройте Настройки из меню приложения. Деморежим расположен вверху. Сведения о картах доступны в разделе «Карты и считыватели», а PIN-коды — в разделе «Сохранённые PIN-коды».

Откройте меню → Настройки. Выберите системное, светлое или тёмное оформление и системный, румынский, английский или русский язык. Изменения применяются к интерфейсу. Снимки используют нативный перевод.

## Управляйте PIN и доступом сайтов

PIN сохраняются через Secret Service/системное хранилище. Если при обычной подписи предлагается запоминание, сохраняйте намеренно и разблокируйте хранилище по запросу. Если оно недоступно, введите PIN для операции. Удаление сохранённых копий не меняет и не разблокирует PIN карты. Подключение браузера включайте только для нужного процесса.

## Оставьте приложение доступным в фоне

Прокрутите Настройки до фоновых параметров и запуска. Фоновая работа сохраняет подключение браузера после закрытия окна. Запуск при входе включает обнаружение в фоне. Открытие при вставке карты работает, пока приложение запущено; это не отдельная постоянная служба.

<GuideScreenshot src="/img/guide/linux/ru/background.png" alt="Оставьте приложение доступным в фоне" steps={[{"text": "Выберите фоновую работу и запуск при необходимости.", "x": 68, "y": 75}, {"text": "Выберите открытие работающего приложения при вставке карты.", "x": 68, "y": 89}]} />

## Найдите версию и обновите безопасно

Откройте меню приложения → О eSemnBun для версии и сайта. Используйте проверку обновлений, если доступна, или исходный канал пакета. Установите совместимую замену; проверка не заменяет приложение автоматически. Для поддержки укажите версии и считыватель, никогда PIN.

<GuideScreenshot src="/img/guide/linux/ru/about.png" alt="Найдите версию и обновите безопасно" steps={[{"text": "Откройте О eSemnBun.", "x": 58, "y": 7}, {"text": "Прочитайте версию и сайт до обращения в поддержку.", "x": 50, "y": 27}]} />

## Откройте справку и команды приложения

Меню содержит Настройки, О программе, Проверку обновлений и Выход. См. [устранение проблем](/docs/troubleshooting) для справки онлайн. Закрытие окна может оставить фоновой процесс; выберите Выход для остановки. Для автоматизации перейдите к руководству Linux CLI.
