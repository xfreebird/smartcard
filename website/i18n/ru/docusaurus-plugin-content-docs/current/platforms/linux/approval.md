В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Подтвердите локальный запрос подписи MCP

В настройках включайте локальные запросы подписи только для работы с выбранным клиентом MCP. Скопируйте указанный закрытый каталог в конфигурацию помощника. Оставьте приложение запущенным. Каждый запрос открывает подготовленный PDF для просмотра: проверьте документ, карту и операцию, явно подтвердите запрос, затем введите PIN в системном диалоге приложения. Сохраненный PIN не заменяет подтверждение. Отменяйте неожиданные запросы.
