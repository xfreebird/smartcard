# Найдите сохранённые документы — Linux

[Все руководства платформы](../linux.md) · [Установка и подключение считывателя](./setup.md)

Откройте сведения о подписи, отправьте файлы и очистите историю.

## Найдите подписанные документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Документы содержат коллекцию результатов и отдельную Историю операций. Запись указывает на файл и не заменяет резервную копию. Перемещённый файл нужно выбрать заново по новому пути.

## Откройте сведения о подписи

Нажмите строку или сведения о подписи для модального окна. Оно проверяет текущий файл, не заменяя рабочую область Проверить и не добавляя операцию. Пример действительно неподписан, поэтому сообщение об отсутствии подписи верно. Закройте окно для возврата; значок папки в списке показывает расположение файла.

## Очистите историю, сохранив документы

Переключитесь на Историю, очистите список и прочитайте подтверждение. Очистка удаляет операции, сохраняя файлы и отдельную коллекцию подписанных документов. Затем вернитесь в коллекцию.
