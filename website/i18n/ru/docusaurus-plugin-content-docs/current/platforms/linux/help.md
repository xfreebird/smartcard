# Решите проблему — Linux

[Все руководства платформы](../linux.md) · [Установка и подключение считывателя](./setup.md)

Безопасно решайте проблемы считывателя, PIN, документов и соединения.

## Безопасное устранение проблем

Нет считывателя: проверьте PC/SC, CCID, кабель и адаптер. Пустой считыватель: вставьте карту и подождите. Неверный владелец: выберите карту до PIN. Неверный/заблокированный PIN: остановитесь и обратитесь к поставщику карты; приложение не может разблокировать её. Файл недоступен: выберите текущий файл. Нет оригинала: восстановите неизменённый оригинал рядом с XML. Для поддержки используйте вымышленный пример, не отправляйте PIN, конфиденциальные документы или полные данные удостоверения.
