## Перед началом

Понадобятся совместимый USB/OTG-считыватель, действующее электронное удостоверение и PIN для подписания. Требуются Android 8 или новее и поддержка USB host. Подписание через NFC недоступно. Выберите канал на странице [Загрузки](/downloads): APK устанавливается на устройство, AAB предназначен для магазина. Обновляйте приложение через тот же канал.

Номера отмечают элементы управления для каждого сценария. Нажмите изображение для увеличения.

В широком окне планшета навигация находится слева, а кнопки подписания — в рабочей области. Поверните планшет горизонтально. В узком или разделённом окне появляется компактная навигация; увеличьте окно для возврата панели. Это снимки планшета, а не увеличенного телефона. См. [руководство телефона](./android.md).
