## Перед началом

Следуйте пронумерованным кружкам для каждой цели. Нажмите изображение для увеличения.

Установите eSemnBun через доступный канал Apple на странице [Загрузки](/downloads) и откройте установленное приложение. Потребуются поддерживаемое активное электронное удостоверение, правильный PIN подписи, совместимый проводной считыватель и [адаптер](/devices). Для USB-C нужно подходящее USB-подключение; для Lightning может потребоваться адаптер с питанием. Подписание через NFC не поддерживается.
