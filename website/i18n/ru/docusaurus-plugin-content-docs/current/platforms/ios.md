## Перед началом

Начиная с eSemnBun 0.2.12, на совместимом iPhone или Android-устройстве можно подписывать документы с совместимой бесконтактной картой по NFC. Можно также использовать совместимый USB-считыватель. Понадобится действующее молдавское электронное удостоверение личности с сертификатом подписи и PIN-кодом подписи. Установите или обновите приложение через канал вашего устройства на странице [Загрузки](/downloads).

Установите eSemnBun через доступный канал Apple на странице [Загрузки](/downloads) и откройте установленное приложение. Потребуются поддерживаемое активное электронное удостоверение, правильный PIN подписи, совместимый проводной считыватель и [адаптер](/devices). Для USB-C нужно подходящее USB-подключение; для Lightning может потребоваться адаптер с питанием. Подписание через NFC не поддерживается.
