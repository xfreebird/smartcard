# Начало работы — Планшет Android

[Все руководства платформы](../android-tablet.md)

Установите приложение, подключите считыватель и выберите карту.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Подключите считыватель и карту

Подключите считыватель через подходящий адаптер. Разрешение относится к USB-устройству, а не ко всем файлам. Для чтения сертификата PIN не нужен.

## Просмотрите или перечитайте карту

Изображение карты показывает данные сертификата и нейтральный аватар, а не фотографию удостоверения. Ключ подписи остаётся на физической карте.
