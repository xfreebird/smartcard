# Зашифруйте файл паролем — Планшет Android

Зашифруйте файл паролем

## Зашифруйте файл паролем

Откройте **Документы**, затем в верхней панели выберите **Другие действия → Защита файлов**. Выберите **Зашифровать** или **Расшифровать**, затем доступный файл.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

В eSemnBun 0.2.13 и новее выберите **Пароль** и укажите AES-128, AES-192 или AES-256. По умолчанию используется AES-256. Чтобы зашифровать файл для получателя, выберите **Сертификат RSA** и укажите его открытый сертификат шифрования (.cer или .der). По умолчанию используйте сертификат шифрования. **Совместимость с открытым ключом карты** явно разрешает открытый ключ RSA карты. Успешный экспорт или шифрование не доказывают возможность расшифровки: соответствующая карта должна поддерживать нужную операцию с закрытым ключом.

Нажмите **Зашифровать** или **Расшифровать**. Результат автоматически сохраняется в закрытом хранилище приложения и появляется в **Документы → Сохранённые документы**. Нажмите **Закрыть** по завершении или **Сохранить как…** для экспорта через выбор файлов Android. Оригинал сохраняется.

Сохранённые документы включают подписанные, зашифрованные и расшифрованные файлы. Определяйте результат по имени файла и метке операции. Шифрование не создаёт цифровую подпись; перед открытием или проверкой содержимого зашифрованный файл нужно расшифровать.
