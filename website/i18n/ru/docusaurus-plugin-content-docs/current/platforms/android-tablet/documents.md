# Найдите сохранённые документы — Планшет Android

[Все руководства платформы](../android-tablet.md) · [Начало работы](./setup.md)

Откройте сведения о подписи, отправьте файлы и очистите историю.

## Найдите подписанные документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Раздел «Документы» содержит библиотеку результатов и отдельную историю. Запись в библиотеке — ссылка на файл, а не резервная копия.

## Просмотрите сведения, сохраняя список

Итог в окне — новая проверка, а не прежняя отметка «подписано». Если файл недоступен, появится ошибка доступа; перемещённый файл выберите заново в разделе проверки.

## Очистите историю, сохранив документы

История содержит действия с документами и запросы сайтов. Её очистка не удаляет библиотеку подписанных документов и файлы на устройстве.
