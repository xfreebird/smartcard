# Подключите агента через MCP — Linux · Командная строка (CLI)

[Все руководства платформы](../linux-cli.md) · [Установка и подключение считывателя](./setup.md)

Выберите доверенные папки и настройте клиент MCP.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Подключите MCP с явным доступом к файлам

Настройте локальный клиент совместимого протокола с абсолютным путём программы и выбранной доверенной папкой. Укажите существующую физическую папку. Корни, заявленные клиентом, не дают прав. Символические ссылки, обход пути и специальные файлы отклоняются. Без корней доступно только обнаружение. Используется stdio, а не сетевой сервис подписи. Лимит8МиБ; оригиналам XML нужен отдельный явно указанный корень.

```sh
esemnbun-mcp --root documents=/home/me/Documents/Signing
```

Начните с `capabilities` и `verify_document`. Вход: `{rootId,relativePath}`; не передавайте PIN или содержимое документа. Возвращаются минимальные метаданные. Клиент может передать их своим внешним сервисам. См. [настройку и правила MCP](https://esemnbun.md/packages/mcp.md).

```json
{
  "command": "/usr/bin/esemnbun-mcp",
  "args": [
    "--root",
    "documents=/home/me/Documents/Signing"
  ]
}
```

```json
{"input":{"rootId":"documents","relativePath":"Contract-semnat.pdf"}}
```

### Включите подписание с подтверждением в приложении

Включите локальные запросы подписи в приложении GNOME и оставьте его запущенным. Добавьте закрытый каталог из настроек в команду помощника ниже. Используйте свой каталог; на снимке показан изолированный каталог съемки. Вызовите `prepare_signing`, просмотрите PDF в приложении, явно подтвердите запрос и введите PIN там, затем получите результат через `get_job`. `cancel_job` запрашивает отмену; отмена или истечение времени не доказывает отсутствие созданной подписи. Никогда не передавайте PIN в аргументах MCP. Этот процесс с подтверждением каждого документа отличается от автоматического подписания ниже.

```sh
esemnbun-mcp \
  --root documents=/home/me/Documents/Signing \
  --broker-directory "$HOME/.local/share/eSemnBun/AgentBroker"
```
