# Альтернатива MoldSign для Windows — электронная подпись

**eSemnBun — независимая альтернатива MoldSign для Windows.** Подписывайте PDF совместимой электронной ID-картой Молдовы через USB-считыватель, проверяйте файлы и подключайте совместимые сайты через локальный мост. Для графического приложения выберите настольный установщик; для терминала и агентов — [инструменты Windows CLI и MCP](./windows-cli.md). eSemnBun не связан со STISC.

Выберите задачу. Для каждой есть отдельное краткое иллюстрированное руководство.

## Перед началом

Относится к **eSemnBun 0.2.6**, Windows 10 **1809 или новее** и Windows 11. Для PowerShell и автоматизации см. [руководство Windows CLI](/docs/platforms/windows-cli/).
