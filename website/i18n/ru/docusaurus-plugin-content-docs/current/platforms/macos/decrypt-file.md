## Расшифруйте полученный файл

Откройте **Документы** и нажмите значок щита рядом с корзиной, чтобы открыть **Защиту файлов**. В форме выберите **Зашифровать** или **Расшифровать**, затем доступный файл.

Получите пароль от отправителя по отдельному доверенному каналу. Выберите зашифрованный файл и введите пароль в поле **Пароль** с рамкой. Считыватель, карта и PIN карты не нужны.

Откройте и проверьте сохранённый результат. Совместимое с MoldSign шифрование не удостоверяет содержимое: успешная расшифровка сама по себе не доказывает целостность или правильность пароля.

Нажмите **Зашифровать** или **Расшифровать**. Новый файл автоматически сохраняется в **Документы → Сохранённые документы**. Нажмите **Готово**, чтобы вернуться, или **Сохранить копию**, чтобы экспортировать его в «Файлы» или другое расположение. Оригинал сохраняется.

Сохранённые документы включают подписанные, зашифрованные и расшифрованные файлы. Определяйте результат по имени файла и метке операции. Шифрование не создаёт цифровую подпись; перед открытием или проверкой содержимого зашифрованный файл нужно расшифровать.
