# Решите проблему — Mac

[Все руководства платформы](../macos.md) · [Установка и подключение считывателя](./setup.md)

Безопасно решайте проблемы считывателя, PIN, документов и соединения.

## Безопасно устраните неполадки

| Что отображается | Следующее действие |
| --- | --- |
| Нет считывателя | Переподключите совместимый считыватель/адаптер, попробуйте прямой USB. |
| Считыватель есть, карты нет | Вставьте/переустановите карту и дождитесь сертификата. |
| Ошибка чтения | Переустановите карту и прочитайте ошибку перед новой операцией. |
| Неверный владелец | Выберите правильную карту до ввода PIN. |
| Неверный PIN / мало попыток | Остановитесь и проверьте PIN: повторные догадки могут заблокировать карту. |
| Файл перемещён / недоступен | Выберите новое место: отсутствие файла не означает неверную подпись. |
| Store не пишет рядом с исходным | Используйте явный экспорт/отправку. |
| Нет результата Spotlight | Проверьте включение, принадлежность приложению, доступность файла и время индексации. |

Установку пакетными менеджерами, терминальную автоматизацию и автономные политики см. в [руководстве CLI для macOS](../macos-cli.md).
