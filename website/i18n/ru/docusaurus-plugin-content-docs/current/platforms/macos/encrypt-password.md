## Зашифруйте файл паролем

В разделе **Документы** выберите **Защита файлов** на панели инструментов. В форме выберите **Зашифровать** или **Расшифровать**, затем доступный файл.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

В версии 0.2.13 выберите **Пароль** и укажите AES-128, AES-192 или AES-256. По умолчанию используется AES-256. Чтобы зашифровать файл для получателя, выберите **Сертификат RSA** и укажите его открытый сертификат шифрования (.cer или .der). Сертификат подписи молдавской ID-карты не может расшифровать эти файлы.

Нажмите **Зашифровать** или **Расшифровать**. Новый файл автоматически сохраняется в **Документы → Сохранённые документы**. Нажмите **Готово**, чтобы вернуться, или **Сохранить копию**, чтобы экспортировать его в «Файлы» или другое расположение. Оригинал сохраняется.

Сохранённые документы включают подписанные, зашифрованные и расшифрованные файлы. Определяйте результат по имени файла и метке операции. Шифрование не создаёт цифровую подпись; перед открытием или проверкой содержимого зашифрованный файл нужно расшифровать.
