# Найдите сохранённые документы — Mac

[Все руководства платформы](../macos.md) · [Установка и подключение считывателя](./setup.md)

Откройте сведения о подписи, отправьте файлы и очистите историю.

## Найдите сохранённый подписанный документ

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Документы и история операций — разные списки. Записи указывают на файлы; если файл перемещён или исчез, заново выберите его в новом месте для проверки.

## Просмотрите и передайте сохранённый документ

Окно сведений использует то же представление, что и проверка. Просмотр сохранённого документа не заменяет файлы в рабочей области проверки. Предпросмотр показывает файл и не является отдельной проверкой безопасности.

## Очистите историю, сохранив документы

Нажмите корзину, прочитайте подтверждение и подтвердите очистку, если хотите удалить список операций. Подписанные файлы и отдельный список подписанных документов сохраняются. Вернитесь к подписанным документам, чтобы продолжить работу.
