# Подпишите документы — Mac

[Все руководства платформы](../macos.md) · [Установка и подключение считывателя](./setup.md)

Добавьте файлы, выберите формат и штамп, подтвердите и сохраните результат.

## Добавьте документы и выберите формат

Для PDF обычно используется PAdES-T: подпись остаётся внутри PDF. Для остальных файлов — отделённая XAdES-T: храните XML вместе с неизменённым оригиналом. Если получателю нужен другой поддерживаемый формат, выберите его у файла в очереди. Меню строки позволяет убрать лишний файл.

## Разместите видимый штамп в PDF

Откройте настройку штампа у PDF в очереди. Видимый штамп необязателен и не заменяет криптографическую подпись. Для многостраничного PDF выберите страницу в предпросмотре.

Текст штампа соответствует выбранному языку приложения: румынскому, английскому или русскому.

## Подтвердите показанный пакет

Введите PIN для подписи выбранной физической карты, а не пароль входа на Mac. После ошибки PIN остановитесь и проверьте владельца и код перед новой попыткой. Счётчик оставшихся попыток защищает карту. Для нового пакета требуется новое подтверждение.

## Дождитесь подписи и метки времени

Не отключайте считыватель во время подписи и получения метки времени. Ошибка сети или метки времени и повреждённый входной файл отличаются от неверного PIN. Сначала прочитайте сообщение об ошибке.

## Найдите, просмотрите и отправьте результат

Отдельная версия macOS обычно создаёт новый файл рядом с исходным, добавляя суффикс и не перезаписывая оригинал. Версия App Store использует разрешённое хранилище и явный экспорт/отправку. Храните отделённый XML вместе с оригиналом.

В версии 0.2.13 из Mac App Store в разделе **Настройки → Основные → Документы** можно выбрать папку для автоматических копий подписанных документов. Выберите папку в системном диалоге, чтобы предоставить приложению доступ.

## Разберитесь с ошибкой документа

В одном пакете могут быть успешные и неуспешные документы. Сохраните готовые результаты. Исправьте входной файл или соединение перед новой операцией; автоматического повтора PIN нет. Неизменённый повреждённый PDF снова завершится ошибкой.
