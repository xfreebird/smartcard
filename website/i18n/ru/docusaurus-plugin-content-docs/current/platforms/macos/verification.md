# Проверьте подпись — Mac

[Все руководства платформы](../macos.md) · [Установка и подключение считывателя](./setup.md)

Проверьте PDF или XML, сведения о подписанте и сертификате.

## Проверьте PDF и каждую подпись

Для проверки не нужны считыватель и PIN. Проверяется выбранный файл, а не видимый штамп или имя файла. Офлайн-проверка не устанавливает текущее состояние отзыва сертификата.

## Изучите целостность, доверие и сертификат

Криптографическая подпись, целостность документа, доверенная цепочка и метка времени — отдельные проверки. Прокрутите страницу к остальным полям сертификата и техническим данным. Регистрационный номер издателя не является личным идентификатором подписанта.

## Проверьте отделённый XML вместе с оригиналом

Добавьте XML в «Проверить». Если хеш документа не проверен, выберите неизменённый оригинал действием выбора исходных файлов в результате. Нужен именно оригинал, а не сам XML. Затем снова прочитайте результат проверки целостности. Одного XML получателю может быть недостаточно.
