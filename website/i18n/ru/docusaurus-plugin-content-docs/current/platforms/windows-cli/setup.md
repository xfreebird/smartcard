# Начало работы — Windows · Командная строка (CLI)

[Все руководства платформы](../windows-cli.md)

Установите приложение, подключите считыватель и выберите карту.

В иллюстрациях используются вымышленные данные. Выполняйте действия в установленном приложении.

## Установите и проверьте доступные возможности

Откройте [Загрузки](/downloads/) и выберите платформу. Архивы CLI содержат терминальные инструменты и MCP; приложение для рабочего стола устанавливается отдельно. Используйте инструкции менеджера пакетов с актуальной версией и отпечатком ключа. Найдите команду и проверьте возможности перед автоматизацией.

<GuideScreenshot src="/img/guide/windows-cli/ru/install.svg" alt="1. Установите и проверьте доступные возможности" caption="Учебный пример команды. Скопируйте команды ниже, заменив пути и имя считывателя." steps={[{"x": 3, "y": 30.6, "text": "Установите через выбранный канал платформы."}, {"x": 3, "y": 78.3, "text": "Проверьте возможности перед обращением к карте."}]} />

```powershell
scoop bucket add esemnbun https://github.com/xfreebird/homebrew-utils
scoop install esemnbun/esemnbun-cli
Get-Command esemnbun
esemnbun capabilities --json
```

Для Chocolatey загрузите .nupkg проекта в пустую папку, затем выполните:

```powershell
choco install esemnbun-cli --source . --yes
```

## Найдите считыватель и проверьте сертификат

Подключите USB-считыватель и вставьте карту. Выведите считыватели, затем прочитайте сертификат без PIN. При нескольких картах укажите точное имя считывателя и проверьте владельца перед подписью. Это учебные команды; считыватель для руководства не использовался.

<GuideScreenshot src="/img/guide/windows-cli/ru/reader.svg" alt="2. Найдите считыватель и проверьте сертификат" caption="Учебный пример команды. Скопируйте команды ниже, заменив пути и имя считывателя." steps={[{"x": 3, "y": 23.8, "text": "Выведите считыватели и наличие карт."}, {"x": 3, "y": 53.5, "text": "Прочитайте нужный сертификат; замените имя считывателя."}, {"x": 3, "y": 83.2, "text": "Вычислите SHA-256 экспортированного сертификата. Для подписи без присутствия используйте эти 64 шестнадцатеричные цифры, а не SHA-1 из cert."}]} />

```powershell
esemnbun readers
esemnbun cert --reader "miniLector EVO" --out leaf.der
Get-FileHash leaf.der -Algorithm SHA256
```
