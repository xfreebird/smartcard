## Поделитесь сертификатом шифрования

По умолчанию команды сертификата/карты используют сертификат шифрования. Добавляйте `--card-public-key` только для явно выбранного режима совместимости с открытым ключом карты. Успешное шифрование или экспорт сертификата не доказывают поддержку расшифровки: соответствующая карта должна поддерживать нужную операцию с закрытым ключом.

Подключите поддерживаемую карту и USB-считыватель. Для экспорта открытого сертификата не нужны документ или PIN. Карта должна предоставлять идентичность шифрования; обычный сертификат подписи её не заменяет.

Учебный пример команды — операция не выполнялась.

<GuideScreenshot src="/img/guide/windows-cli/ru/protect-export.svg" alt="Поделитесь сертификатом шифрования" steps={[{"x": 20, "y": 25, "text": "Выполните команду со своими файлами. Используйте новый путь результата. Вводите секреты только в скрытом приглашении; замените SHA256 полным отпечатком сертификата шифрования."}]} />

```sh
esemnbun encryption-certs
esemnbun encryption-certs --card SHA256 --out recipient.cer
```

Передавайте только recipient.cer; экспорт не требует PIN и не извлекает закрытый ключ.
