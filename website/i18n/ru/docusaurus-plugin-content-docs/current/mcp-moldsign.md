# MoldSign MCP: электронная подпись для локальных ИИ-агентов

**eSemnBun предоставляет локальный сервер Model Context Protocol (MCP) для проверки подписей и, при явной настройке, подписания PDF поддерживаемой электронной ID-картой Молдовы.** Он работает на Windows, macOS и Linux. Это независимый проект, а не официальный MCP-сервис MoldSign или STISC.

MCP подключает агента к установленным инструментам. Сайт eSemnBun публикует документацию и загрузки; он не предоставляет удалённый сервис подписи. Процесс MCP работает на компьютере с доступом к выбранным файлам и, для подписи, к считывателю карт.

## Выберите нужный компонент

| Компонент | Назначение |
| --- | --- |
| Настольное приложение | Подпись и проверка документов в графическом интерфейсе |
| Совместимый с MoldSign мост браузера | Обработка поддерживаемых запросов от MSign и других разрешённых сайтов |
| MCP-сервер eSemnBun | Доступ MCP-клиента к явно настроенным локальным инструментам через stdio |

Это разные интерфейсы. Работающий мост браузера не настраивает агента автоматически, а публикация сайта не предоставляет облачным агентам доступ к вашему считывателю.

## Установка на Windows, Mac или Linux

Начните с [загрузок](/downloads/) и откройте руководство установленного CLI-пакета:

| Платформа | Команда MCP | Настройка |
| --- | --- | --- |
| Windows | `esemnbun.exe mcp` | [MCP для Windows](./platforms/windows-cli/mcp.md) |
| Mac / macOS | `esemnbun-mcp` | [MCP для Mac](./platforms/macos-cli/mcp.md) |
| Linux | `esemnbun-mcp` | [MCP для Linux](./platforms/linux-cli/mcp.md) |

Укажите абсолютный путь к исполняемому файлу и отдельную существующую папку входных документов. Приложению Mac App Store нужен отдельно установленный CLI. SSH, WSL и контейнеры имеют собственный доступ к файлам и устройствам.

[Руководство по настройке агентов](https://esemnbun.md/docs/integrations/mcp-agents/) (на английском) содержит примеры для Claude, Codex, Cursor, GitHub Copilot, Gemini CLI и других клиентов, а также архив интеграций. Примеры не подтверждают проверку подключения к каждому клиенту в работе. Выберите клиент, совместимый с версиями протокола из [контракта MCP](https://esemnbun.md/packages/mcp.md) (на английском).

## Что может делать агент

| Инструмент | Назначение и условие |
| --- | --- |
| `capabilities` | Получить разрешённые папки, форматы и доступные режимы подписи |
| `verify_document` | Проверить PDF или XML в разрешённой папке без обращения к считывателю или сети |
| `prepare_signing` | Подготовить подпись PDF PAdES-T, если настроено подтверждение в нативном приложении |
| `get_job`, `cancel_job` | Проверить состояние или запросить отмену задания в том же активном соединении |
| `sign_document` | Подписать только при явной настройке оператором режима без присутствия |

Для проверки используйте вымышленный подписанный документ в выбранной папке. Пример входных данных инструмента:

```json
{"input":{"rootId":"documents","relativePath":"Contract-signed.pdf"}}
```

Читайте результат проверки подписи, а не только статус выполнения вызова. Для отсоединённых XML-подписей нужны оригиналы и явно выбранная папка оригиналов. Офлайн-проверка не устанавливает текущее состояние отзыва сертификата.

## Подпись и конфиденциальность

Подпись требует поддерживаемую карту, действующий сертификат подписи, совместимый USB-считыватель и авторизацию. Закрытый ключ остаётся на карте. Настройка проверки по умолчанию не включает подпись без присутствия.

Подтверждение в приложении или подпись без присутствия с закреплённым сертификатом настраиваются отдельно по руководству платформы. Не вводите PIN карты в чат, аргументы инструментов или примеры конфигурации. Сервер возвращает минимальные метаданные проверки, а не содержимое документов; MCP-клиент может отправлять эти метаданные собственным внешним сервисам.

## Документация для агентов

Сайт предоставляет [текстовый индекс](https://esemnbun.md/ru/llms.txt), [объединённую справку](https://esemnbun.md/ru/llms-full.txt) и [каталог JSON](https://esemnbun.md/ru/discovery.json). Файлы создаются из публичных руководств и ссылаются на HTML-страницы для цитирования. JSON-каталог описывает сайт; это не MCP-сервис и не команда установки.

Для обычной подписи начните с [альтернативы MoldSign](./moldsign.md) или [подписи и проверки](./signing.md).
