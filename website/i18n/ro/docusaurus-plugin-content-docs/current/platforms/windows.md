# Alternativă MoldSign pentru Windows — semnătură electronică

**eSemnBun este o alternativă independentă la MoldSign pentru Windows.** Semnează PDF-uri cu o carte de identitate electronică acceptată din Moldova și un cititor USB, verifică fișiere și conectează site-uri compatibile prin serviciul local pentru browser. Alege instalatorul desktop pentru aplicația grafică sau [instrumentele Windows CLI și MCP](./windows-cli.md) pentru terminal și agenți. eSemnBun nu este afiliat cu STISC.

Alege ce vrei să faci. Fiecare activitate are un ghid ilustrat separat.

## Înainte de a începe

Se aplică versiunii **eSemnBun 0.2.13**, Windows 10 **1809 sau ulterior** și Windows 11. Consultă [ghidul CLI pentru Windows](/docs/platforms/windows-cli/) pentru PowerShell și automatizare.
