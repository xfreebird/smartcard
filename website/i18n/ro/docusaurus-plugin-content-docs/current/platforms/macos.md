# Alternativă MoldSign pentru Mac — semnătură electronică pe macOS

**eSemnBun este o alternativă independentă la MoldSign pentru Mac (macOS).** Folosește o carte de identitate electronică acceptată din Moldova și un cititor USB pentru semnare PDF, semnături XAdES și verificarea documentelor. Ediția DMG și ediția Mac App Store folosesc fluxuri diferite pentru browser. [Instrumentele CLI și MCP](./macos-cli.md) se instalează separat; pachetul CLI din Homebrew nu este aplicația desktop. eSemnBun nu este afiliat cu STISC.

Alege ce vrei să faci. Fiecare activitate are un ghid ilustrat separat.
