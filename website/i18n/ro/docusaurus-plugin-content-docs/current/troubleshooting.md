# Dacă ceva nu funcționează

## Cititorul sau cardul nu apare

Reconectează cititorul, verifică adaptorul și reintrodu cardul. Încearcă o conexiune directă, fără hub. Verifică dacă sistemul recunoaște cititorul. Pe desktop poate fi disponibil un utilitar configurabil pentru detectarea introducerii.

## PIN greșit

Oprește-te și verifică ce card este selectat. Nu încerca repetat coduri la întâmplare: cardul se poate bloca. Pentru deblocare, contactează furnizorul oficial al cardului.

## Conexiunea cu browserul

O altă aplicație de semnare poate ocupa portul local. Închide aplicația concurentă și reconectează din setările eSemnBun. Verifică atent cererile browserului privind accesul la rețeaua locală.

## Raportează o problemă

Include versiunile aplicației și sistemului, modelul cititorului și pașii de reproducere. Folosește documente fictive. Nu atașa PIN-uri, fotografii ale cardului, chei private sau fișiere confidențiale. Vezi [Suport](/support).
