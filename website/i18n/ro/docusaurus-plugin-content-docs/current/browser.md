# Folosește cardul pe site-uri compatibile

Aplicația oferă scurtături către servicii precum MSign și EVO. Acestea sunt operate separat și au propriile condiții.

Pe dispozitivele mobile compatibile, poți utiliza browserul din aplicație sau conexiunea cu browserul extern, unde este disponibilă. Browserul integrat oferă adresă URL, navigare înainte/înapoi și ștergerea datelor. Unele pagini de autentificare cu cardul necesită afișarea versiunii desktop.

Pe Mac, atât ediția Mac App Store, cât și ediția independentă detectează cititoare USB compatibile și cardurile introduse și permit Browser-ul integrat și browserele externe compatibile. Lasă eSemnBun pornit pe același Mac, activează **Configurări → Conexiune cu browserul** și acordă permisiunea de rețea locală cerută de browser. Urmează [configurarea browserului pe Mac](./platforms/macos/browser.md).

Verifică adresa site-ului, identitatea și operația înainte de autorizare. Ștergerea cookie-urilor te poate deconecta de pe site-uri, fără să șteargă documentele sau PIN-urile salvate.
