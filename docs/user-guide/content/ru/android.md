# Телефон Android

Понадобятся совместимый USB/OTG-считыватель, действующее электронное удостоверение и PIN для подписания. Требуются Android 8 или новее и поддержка USB host. Подписание через NFC недоступно. Выберите канал на странице [Загрузки](/downloads): APK устанавливается на устройство, AAB предназначен для магазина. Обновляйте приложение через тот же канал.

Номера отмечают элементы управления для каждого сценария. Нажмите изображение для увеличения.

Нижняя панель открывает подписание, проверку, файлы, браузер и карту. В широком горизонтальном окне доступны боковая навигация и расположение карты рядом с файлами. Узкие окна сохраняют компактный вид. См. [руководство планшета](./android-tablet.md).

## 1. Подключите считыватель и карту

Подключите считыватель через подходящий адаптер. Разрешение относится к USB-устройству, а не ко всем файлам. Для чтения сертификата PIN не нужен.

## 3. Выберите подпись PDF или XML

Подпись PDF (PAdES-T) встраивается в PDF. XAdES создаёт XML: храните исходный файл вместе с отсоединённой подписью. Форматам с меткой времени и данными проверки нужны соответствующие службы доверия. Видимый штамп необязателен и не заменяет цифровую подпись.

Подписи полей штампа соответствуют языку приложения, выбранному в общих настройках.

Недействительность означает сбой проверки целостности или криптографической подписи. Возможны изменённые байты либо повреждённая/неверная подпись. Видимый штамп, знакомое имя файла или автор не отменяют этот результат.

## Разберите неподтверждённую цепочку доверия

Неподтверждённость отличается от недействительности. В примере подпись и целостность верны, но сертификат не входит в распознанную цепочку MDQSign. Отсутствие оригинала также может дать неподтверждённый результат, но с другим объяснением.

## Решение проблем

| Проблема | Что сделать |
| --- | --- |
| Считыватель не найден | Проверьте OTG/USB host, адаптер и кабель; переподключите и разрешите USB-доступ. |
| Карта пуста или не читается | Вставьте карту заново, подождите и повторите чтение. |
| Неверный PIN или предупреждение об оставшихся попытках | Остановитесь и проверьте карту и PIN. Повторные ошибки могут заблокировать карту. |
| Ошибка сети или метки времени | Проверьте соединение и сообщение службы, затем готовые результаты перед повтором. |
| Файл перемещён или находится в облаке | Скачайте его и выберите заново в разделе проверки. |
| Проблема входа/загрузки на сайте | Проверьте адрес и соединение. Для загрузок после входа может понадобиться внешний браузер. |

Объяснения результатов: [Подписание и проверка](/docs/signing). Считыватели и адаптеры: [Устройства](/devices).

## Зашифруйте файл паролем

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

## Зашифруйте для владельца сертификата

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Попросите у получателя открытый сертификат шифрования (.cer/.der), экспортированный по следующему руководству. Подтвердите отпечаток с владельцем по доверенному каналу. Сертификата только для подписи недостаточно. Для шифрования нужен открытый сертификат, а не карта, закрытый ключ или PIN получателя.

## Расшифруйте полученный файл

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Уточните у отправителя метод. Для файла с паролем получите пароль отдельно. Для файла с сертификатом подключите соответствующую поддерживаемую карту и считыватель; нужны ключ шифрования и PIN. Другая карта или карта только для подписи не подойдёт.

<GuideScreenshot src="/img/guide/android-phone/ru/protect-decrypt-light.png" alt="Расшифруйте полученный файл" steps={[{"x": 27, "y": 20, "text": "Выберите Расшифровать и полученный зашифрованный файл."}, {"x": 25, "y": 55, "text": "Выберите Пароль и введите пароль от отправителя."}, {"x": 50, "y": 88, "text": "Нажмите Расшифровать и сохраните результат под новым именем."}]} />

Для расшифровки картой выберите Сертификат/карта, затем чтение карты. Выберите нужную идентичность шифрования, проверьте сведения, введите PIN и нажмите Расшифровать. Сохраните под новым именем. Если подходящей идентичности нет, запросите копию с паролем. После ошибки PIN остановитесь; не повторяйте автоматически.

Откройте и проверьте сохранённый результат. Совместимое с MoldSign шифрование не удостоверяет содержимое: успешная расшифровка сама по себе не доказывает целостность или правильность пароля.


## Поделитесь сертификатом шифрования

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Подключите поддерживаемую карту и USB-считыватель. Для экспорта открытого сертификата не нужны документ или PIN. Карта должна предоставлять идентичность шифрования; обычный сертификат подписи её не заменяет.

<GuideScreenshot src="/img/guide/android-phone/ru/protect-certificate-light.png" alt="Зашифруйте для владельца сертификата" steps={[{"x": 27, "y": 43, "text": "Выберите Сертификат/карта."}, {"x": 26, "y": 63, "text": "Выберите чтение карты; при необходимости прокрутите."}]} />

После чтения выберите нужную идентичность и раскройте сведения о сертификате. Экспортируйте сертификат шифрования, сохраните .cer и передайте отправителю. Отдельно сравните отпечаток. Экспортируется только открытый сертификат; закрытый ключ остаётся на карте. На снимке показан начальный экран до чтения.
