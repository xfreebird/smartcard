# Linux — иллюстрированное руководство

Следуйте пронумерованным снимкам eSemnBun 0.2.13 для Linux. Нажмите изображение для увеличения и выберите Исходный размер для мелких элементов.

Установите настольный пакет для вашей системы и архитектуры из раздела [Загрузки](/downloads/), затем откройте приложение из меню. Настольные DEB/RPM/Flatpak запускают графическое приложение; репозитории и архивы CLI устанавливают терминальные инструменты. См. [руководство Linux CLI](./linux-cli.md) для терминала и MCP. Ubuntu 24.04/Fedora — поддерживаемые настольные системы; проверяйте требования пакета. Нужны действующее поддерживаемое удостоверение, правильный PIN подписи, совместимый USB-считыватель и адаптер. NFC не поддерживается. Закрытый ключ остаётся на карте.

Нужны PC/SC и драйвер CCID. Ubuntu: `sudo apt install pcscd libccid`. Fedora: `sudo dnf install pcsc-lite pcsc-lite-ccid`. Включите сокет: `sudo systemctl enable --now pcscd.socket`. Запускайте приложение в графической сессии; политика доступа через SSH может отличаться.

## 1. Подключите считыватель

Подключите считыватель напрямую или через нужный USB-адаптер. Обнаружение и чтение сертификата не требуют PIN. Ошибка PC/SC отличается от отсутствующего считывателя.

## 2. Вставьте карту

Вставьте удостоверение и дождитесь чтения сертификата. Проверьте владельца и срок действия. Не переподключайте устройство повторно во время операции.

## 3. Выберите нужную личность

При нескольких картах выберите нужную в карусели. Изображение карты использует данные сертификата и нейтральный аватар, а не фото удостоверения. При необходимости перечитайте карту кнопкой обновления.

## 4. Добавьте документы пакета

Выберите или перетащите все нужные файлы в Подписать. Можно выбрать несколько документов. Проверьте имена и удалите лишнее до разрешения. Перетаскивание зависит от файлового менеджера; выбор файлов остаётся доступным.

## 5. Выберите формат подписи

Подпись PDF — PAdES-T внутри PDF. Подпись XML — XAdES-BES; XML с отметкой времени — XAdES-T; XML с данными проверки — XAdES-C. Отметки времени и данные статуса требуют соответствующих сетевых служб. Сохраняйте отделённый XML с неизменённым оригиналом.

## 6. Разместите необязательный PDF-штамп

Откройте меню файла и добавьте штамп. Видимый штамп необязателен и не заменяет криптографическую подпись. Не закрывайте важный текст. Пример PDF явно помечен как неподписанный.

## 7. Проверьте и разрешите пакет

Используйте PIN подписи выбранной карты, а не пароль Linux. Проверьте владельца и весь список. Новый пакет требует нового разрешения. После неверного PIN остановитесь и уточните его: повторные догадки могут заблокировать карту. Диалог примера не обращается к настоящему хранилищу и отключает сохранение.

## 8. Дождитесь подписи и отметки времени

Оставьте считыватель подключённым до результата. Отметка времени требует сети. Сетевая ошибка отличается от неверного PIN; прочитайте сообщение до нового осознанного запроса.

## 9. Найдите готовый файл

Приложение создаёт отдельный результат, сохраняя исходник. Откройте готовую строку для просмотра/поиска файла. Сохраняйте оригинал с отделённым XML.

## 10. Разберитесь с ошибкой файла

В пакете могут быть готовые файлы и ошибки. Сохраните готовое, прочитайте сообщение и исправьте причину до нового запроса. Автоматического повтора PIN и исправления повреждённых файлов нет.

## 11. Проверьте PDF

Проверка не требует карты или PIN. Откройте Проверить и выберите/перетащите подписанный PDF/XML. Поддерживается несколько файлов. Читайте каждую подпись, а не полагайтесь на имя или штамп. Офлайн-проверка не устанавливает текущий статус отзыва сертификата.

Прокрутите результат и раскройте сведения о сертификате и технические данные. Целостность, криптографическая подпись, доверие и отметка времени — отдельные проверки. Сведения организации-издателя не являются личным идентификатором подписанта.

Неизвестная/неподтверждённая цепочка отличается от доказанного изменения. Проверяйте целостность и подпись отдельно и учитывайте правила получателя для сертификатов.

Отсутствие распознанной подписи означает, что приложение не нашло проверяемую подпись. Сканированная картинка или штамп её не заменяют. Попросите настоящий электронный подписанный результат.

## 16. Проверьте отделённый XML с оригиналом

Для отделённого XAdES положите точный неизменённый оригинал рядом с XML под именем из ссылки подписи, затем снова выберите XML в Проверить. В Linux пока нет встроенного выбора оригиналов: связь разрешается из папки XML. Отсутствующий оригинал не позволяет полностью проверить целостность.

## 17. Найдите подписанные документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Документы содержат коллекцию результатов и отдельную Историю операций. Запись указывает на файл и не заменяет резервную копию. Перемещённый файл нужно выбрать заново по новому пути.

## 20. Выберите язык и оформление

Откройте Настройки из меню приложения. Деморежим расположен вверху. Сведения о картах доступны в разделе «Карты и считыватели», а PIN-коды — в разделе «Сохранённые PIN-коды».

Откройте меню → Настройки. Выберите системное, светлое или тёмное оформление и системный, румынский, английский или русский язык. Изменения применяются к интерфейсу. Снимки используют нативный перевод.

## Используйте сайты в своём браузере

Linux использует внешний браузер, без встроенного браузера и менеджера закладок Apple/Android. В Настройках включите подключение и откройте поддерживаемый сервис на этом же компьютере. Оставьте приложение запущенным. Проверьте адрес сайта, документы, карту и операцию в окне согласия/PIN. Штампы сайтов необязательны. Старый доступ MoldSign Desktop разрешайте только нужному клиенту. Встроенная HTTPS-идентичность используется автоматически; Импорт намеренно её заменяет. Не обходите предупреждения сертификата. Если порты заняты, завершите чужую операцию и устраните конфликт. Закладки, cookie и история принадлежат внешнему браузеру. Согласие сайта, доступ к хранилищу PIN и завершение на портале не продемонстрированы изолированными снимками.

## Безопасное устранение проблем

Нет считывателя: проверьте PC/SC, CCID, кабель и адаптер. Пустой считыватель: вставьте карту и подождите. Неверный владелец: выберите карту до PIN. Неверный/заблокированный PIN: остановитесь и обратитесь к поставщику карты; приложение не может разблокировать её. Файл недоступен: выберите текущий файл. Нет оригинала: восстановите неизменённый оригинал рядом с XML. Для поддержки используйте вымышленный пример, не отправляйте PIN, конфиденциальные документы или полные данные удостоверения.

## Зашифруйте файл паролем

Откройте главное меню в заголовке окна, затем **Защита файлов → Зашифровать**, **Расшифровать** или **Удалить файл**. Выберите доступный файл; при необходимости прокрутите форму.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

Выберите **Пароль** и укажите AES-128, AES-192 или AES-256. По умолчанию используется AES-256. Чтобы зашифровать файл для получателя, выберите **Сертификат RSA** и укажите его открытый сертификат шифрования (.cer или .der). По умолчанию используйте сертификат шифрования. **Совместимость с открытым ключом карты** явно разрешает открытый ключ RSA карты. Успешный экспорт или шифрование не доказывают возможность расшифровки: соответствующая карта должна поддерживать нужную операцию с закрытым ключом.

## Удалите локальный файл

Откройте главное меню в заголовке окна, затем **Защита файлов → Зашифровать**, **Расшифровать** или **Удалить файл**. Выберите доступный файл; при необходимости прокрутите форму.

Только на компьютере. После подтверждения безвозвратно удаляется один поддерживаемый обычный локальный файл. Стирание с SSD, снимков, резервных и других копий не гарантируется. Неподдерживаемые расположения и ссылки отклоняются. Мобильные поставщики документов не поддерживают операцию.
