# Планшет Android

Понадобятся совместимый USB/OTG-считыватель, действующее электронное удостоверение и PIN для подписания. Требуются Android 8 или новее и поддержка USB host. Подписание через NFC недоступно. Выберите канал на странице [Загрузки](/downloads): APK устанавливается на устройство, AAB предназначен для магазина. Обновляйте приложение через тот же канал.

Номера отмечают элементы управления для каждого сценария. Нажмите изображение для увеличения.

В широком окне планшета навигация находится слева, а кнопки подписания — в рабочей области. Поверните планшет горизонтально. В узком или разделённом окне появляется компактная навигация; увеличьте окно для возврата панели. Это снимки планшета, а не увеличенного телефона. См. [руководство телефона](./android.md).

## 1. Подключите считыватель и карту

Подключите считыватель через подходящий адаптер. Разрешение относится к USB-устройству, а не ко всем файлам. Для чтения сертификата PIN не нужен.

## 3. Выберите подпись PDF или XML

Подпись PDF (PAdES-T) встраивается в PDF. XAdES создаёт XML: храните исходный файл вместе с отсоединённой подписью. Форматам с меткой времени и данными проверки нужны соответствующие службы доверия. Видимый штамп необязателен и не заменяет цифровую подпись.

Подписи полей штампа соответствуют языку приложения, выбранному в общих настройках.

Проверьте владельца, имена документов, формат и запрашивающий сайт. В текущей версии Android PIN вводится для каждого нового подтверждения; сохранение PIN не предлагается. Не сообщайте PIN службе поддержки.

## 10. Найдите подписанные документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Раздел «Документы» содержит библиотеку результатов и отдельную историю. Запись в библиотеке — ссылка на файл, а не резервная копия.

## 15. Язык, оформление, демонстрация и поддержка

В Android 13+ язык также доступен в системных Настройках → Приложения → eSemnBun → Язык. В Общих также доступны штампы для браузера и удаление сохранённого PIN выбранной карты.

## Решение проблем

| Проблема | Что сделать |
| --- | --- |
| Считыватель не найден | Проверьте OTG/USB host, адаптер и кабель; переподключите и разрешите USB-доступ. |
| Карта пуста или не читается | Вставьте карту заново, подождите и повторите чтение. |
| Неверный PIN или предупреждение об оставшихся попытках | Остановитесь и проверьте карту и PIN. Повторные ошибки могут заблокировать карту. |
| Ошибка сети или метки времени | Проверьте соединение и сообщение службы, затем готовые результаты перед повтором. |
| Файл перемещён или находится в облаке | Скачайте его и выберите заново в разделе проверки. |
| Проблема входа/загрузки на сайте | Проверьте адрес и соединение. Для загрузок после входа может понадобиться внешний браузер. |

Объяснения результатов: [Подписание и проверка](/docs/signing). Считыватели и адаптеры: [Устройства](/devices).

## Зашифруйте файл паролем

Откройте меню **Ещё** на панели навигации и выберите **Защита файлов**. Выберите **Зашифровать** или **Расшифровать**, затем доступный файл.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

Защита файлов использует пароль. Шифрование сертификатом/картой недоступно для молдавской ID-карты: её сертификат подписи не может расшифровывать файлы. Если получен файл, зашифрованный сертификатом, попросите копию с паролем.

Нажмите **Зашифровать** или **Расшифровать**. Результат автоматически сохраняется в закрытом хранилище приложения и появляется в **Документы → Сохранённые документы**. Нажмите **Закрыть** по завершении или **Сохранить как…** для экспорта через выбор файлов Android. Оригинал сохраняется.

Сохранённые документы включают подписанные, зашифрованные и расшифрованные файлы. Определяйте результат по имени файла и метке операции. Шифрование не создаёт цифровую подпись; перед открытием или проверкой содержимого зашифрованный файл нужно расшифровать.

Получите пароль от отправителя по отдельному доверенному каналу. Выберите зашифрованный файл и введите пароль в поле **Пароль** с рамкой. Считыватель, карта и PIN карты не нужны.
