# Планшет Android

Начиная с eSemnBun 0.2.12, на совместимом iPhone или Android-устройстве можно подписывать документы с совместимой бесконтактной картой по NFC. Можно также использовать совместимый USB-считыватель. Понадобится действующее молдавское электронное удостоверение личности с сертификатом подписи и PIN-кодом подписи. Установите или обновите приложение через канал вашего устройства на странице [Загрузки](/downloads).

Номера отмечают элементы управления для каждого сценария. Нажмите изображение для увеличения.

В широком окне планшета навигация находится слева, а кнопки подписания — в рабочей области. Поверните планшет горизонтально. В узком или разделённом окне появляется компактная навигация; увеличьте окно для возврата панели. Это снимки планшета, а не увеличенного телефона. См. [руководство телефона](./android.md).

## 1. Подключите считыватель и карту

Понадобится действующее молдавское электронное удостоверение личности с сертификатом подписи и PIN-кодом подписи.

### Подпишите по NFC

Начиная с eSemnBun 0.2.12, на совместимом iPhone или Android-устройстве можно подписывать документы с совместимой бесконтактной картой по NFC. Можно также использовать совместимый USB-считыватель. На экране **Подписать** выберите **С телефона · NFC** и добавьте документ. Нажмите **Продолжить**, проверьте запрос и подтвердите PIN-код подписи. Держите карту возле NFC-антенны телефона до сообщения о завершении. На Android включите NFC.

<GuideScreenshot src="/img/guide/android-tablet/ru/nfc-sign.png" alt="Экран подписания с выбранным NFC" steps={[{"text": "Экран подписания с выбранным NFC", "x": 45, "y": 75}]} />

### Подпишите через USB-считыватель

Для USB подключите считыватель через подходящий [адаптер](/devices), выберите **Со считывателем карт** на экране **Подписать** и вставьте карту. Если подключено несколько карт, выберите нужного владельца перед продолжением.

## 2. Добавьте файлы и подготовьте пакет

### Выберите способ подписи

На экране **Подписать** выберите **С телефона · NFC** и добавьте документ. Нажмите **Продолжить**, проверьте запрос и подтвердите PIN-код подписи. Держите карту возле NFC-антенны телефона до сообщения о завершении. На Android включите NFC.

Для USB подключите считыватель через подходящий [адаптер](/devices), выберите **Со считывателем карт** на экране **Подписать** и вставьте карту. Если подключено несколько карт, выберите нужного владельца перед продолжением. При использовании USB оставьте считыватель подключённым, а карту вставленной до завершения подписи и получения метки времени.

Не отключайте считыватель до появления всех результатов. Исходный файл хранится отдельно от подписанного. Документы также можно передать в eSemnBun через меню «Поделиться» другого приложения.

## 3. Выберите подпись PDF или XML

Подпись PDF (PAdES-T) встраивается в PDF. XAdES создаёт XML: храните исходный файл вместе с отсоединённой подписью. Форматам с меткой времени и данными проверки нужны соответствующие службы доверия. Видимый штамп необязателен и не заменяет цифровую подпись.

## 10. Найдите подписанные документы

Сохранённые документы содержат подписанные, зашифрованные и расшифрованные результаты. Выберите подписанный файл для просмотра сведений о подписи. Для зашифрованного файла доступна расшифровка; зашифрованное содержимое не отправляется на проверку подписи. Расшифрованные файлы сохраняют метку типа результата; их можно открыть или экспортировать.

Раздел «Документы» содержит библиотеку результатов и отдельную историю. Запись в библиотеке — ссылка на файл, а не резервная копия.

## Решение проблем

| Проблема | Что сделать |
| --- | --- |
| Считыватель не найден | Проверьте OTG/USB host, адаптер и кабель; переподключите и разрешите USB-доступ. |
| Карта пуста или не читается | Вставьте карту заново, подождите и повторите чтение. |
| Неверный PIN или предупреждение об оставшихся попытках | Остановитесь и проверьте карту и PIN. Повторные ошибки могут заблокировать карту. |
| Ошибка сети или метки времени | Проверьте соединение и сообщение службы, затем готовые результаты перед повтором. |
| Файл перемещён или находится в облаке | Скачайте его и выберите заново в разделе проверки. |
| Проблема входа/загрузки на сайте | Проверьте адрес и соединение. Для загрузок после входа может понадобиться внешний браузер. |

Объяснения результатов: [Подписание и проверка](/docs/signing). Считыватели и адаптеры: [Устройства](/devices).

## Зашифруйте файл паролем

Откройте **Документы**, затем в верхней панели выберите **Другие действия → Защита файлов**. Выберите **Зашифровать** или **Расшифровать**, затем доступный файл.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

В eSemnBun 0.2.13 и новее выберите **Пароль** и укажите AES-128, AES-192 или AES-256. По умолчанию используется AES-256. Чтобы зашифровать файл для получателя, выберите **Сертификат RSA** и укажите его открытый сертификат шифрования (.cer или .der). По умолчанию используйте сертификат шифрования. **Совместимость с открытым ключом карты** явно разрешает открытый ключ RSA карты. Успешный экспорт или шифрование не доказывают возможность расшифровки: соответствующая карта должна поддерживать нужную операцию с закрытым ключом.
