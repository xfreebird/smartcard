# Настольное приложение для Windows

Относится к **eSemnBun 0.2.6**, Windows 10 **1809 или новее** и Windows 11. Для PowerShell и автоматизации см. [руководство Windows CLI](/docs/platforms/windows-cli/).

## Установите подходящую редакцию

Для самостоятельной установки используйте **MSI** из [GitHub Releases](https://github.com/xfreebird/smartcard/releases/latest) или установите [eSemnBun из Microsoft Store](https://apps.microsoft.com/detail/9pdpr6rnt42s?hl=en-US&gl=MD). Выберите архитектуру своего компьютера среди файлов выпуска. Неподписанный MSIX для разработки может требовать сертификат подписи и не заменяет публичный MSI.

1. Запустите MSI и завершите установку либо установите приложение из магазина.
2. Откройте **eSemnBun** через Пуск. При первом запуске появится главное окно.
3. Подключите считыватель. miniLector использует драйвер CCID и службу Smart Card Windows.
4. Вставьте карту и дождитесь сертификата. Перед подписью проверьте владельца и срок действия.





Несколько карт отображаются в горизонтальной карусели. Выберите расположенную по центру карту, которой собираетесь подписывать. Иллюстрация использует сведения сертификата и нейтральный аватар, а не фотографию удостоверения.

## Подпишите документы из приложения или Проводника

В **Sign (Подписать)** перетащите документы в область с пунктирной рамкой или выберите **Choose files… (Выбрать файлы…)**. Если установленная редакция поддерживает контекстное меню Проводника, можно также отправить выбранные файлы из Проводника в eSemnBun.

1. Добавьте файлы и проверьте формат рядом с каждым.
2. Для PDF используйте **PAdES-T**, чтобы встроить подпись в PDF. XAdES создаёт XML; отделённый XML нужно хранить вместе с исходным документом.
3. Подтвердите выбранную личность, нажмите **Sign (Подписать)** и проверьте запрос авторизации перед вводом PIN карты или подтверждением сохранённой записи.
4. Не отключайте считыватель до завершения. Действия результата позволяют открыть или найти созданные файлы.

Авторизация пакета относится к утверждённому списку документов и выбранной карте. Если элемент завершился ошибкой, изучите её перед повторной попыткой. Не путайте готовые результаты с неподписанными исходниками. См. [форматы подписи и ошибки](/docs/signing).

## Проверьте подписи и просмотрите действия

Откройте **Verify (Проверить)** и выберите или перетащите подписанный PDF/XML. Для отделённой XML-подписи нужен также оригинал документа. Проверьте подписанта, целостность, цепочку сертификатов и доступные проверки метки времени. Правильное имя файла или зелёный статус карты не доказывают действительность подписи документа.

**Документы → История** записывает недавние операции и предлагает действия для доступных файлов. Очистка истории не удаляет сами подписанные документы.

## Настройки, PIN и значок в области уведомлений

Настройки включают язык (румынский, английский, русский), оформление, управление сохранёнными PIN, параметры запуска и открытия при подключении считывателя, соединение с браузером, демонстрационный режим и сведения о приложении. Часть элементов зависит от установленной редакции.

Сохранённый PIN использует средства безопасности и аутентификации Windows. Удаление убирает сохранённую приложением запись и не меняет PIN физической карты. Перед удалением проверьте, какой карте принадлежит запись.

Значок в области уведомлений открывает приложение и его действия. После закрытия главного окна eSemnBun может продолжать работать; для остановки выберите **Quit (Выход)**. В Настройках укажите, открывать ли приложение при входе в систему или подключении считывателя/карты. Сначала включите нужный параметр, затем переподключите считыватель и проверьте поведение.

Демонстрационный режим требует согласия, показывает вымышленные карты и примеры документов и остаётся обозначенным при обычном использовании. Выключите его, чтобы вернуться к своему считывателю. Раздел О приложении показывает значок, автора, версию и сайт.

## Используйте соединение с браузером

В Настройках включите **Browser connection (Соединение с браузером)**. Откройте поддерживаемый сервис в браузере на том же компьютере Windows. Получив запрос, проверьте сайт, файлы и выбранную карту перед авторизацией.

Если порты заняты другим сервером MoldSign, завершите активные операции приложения поставщика и воспользуйтесь предложенным действием устранения конфликта, если оно доступно. Порты 18480/18443 одновременно может использовать только один bridge. Если браузер запрашивает доступ к локальной сети, разрешите его для нужного сервиса, чтобы он мог связаться с локальным bridge. См. [сервисы в браузере](/docs/browser).

## Обновите приложение или устраните проблему

Установки Microsoft Store обновляются через магазин. Самостоятельные сборки предлагают проверку обновлений с переходом на страницу загрузки; установите новый MSI выпуска.

| Симптом | Следующий шаг |
| --- | --- |
| Считыватель отсутствует | Найдите считыватель смарт-карт в Диспетчере устройств; переподключите его и проверьте службу Smart Card. |
| Сертификат не загружается | Вставьте карту заново и дождитесь окончания чтения. |
| Выбрана другая личность | Выберите нужную карту перед вводом её PIN. |
| Порт браузера занят | Остановите распознанный конкурирующий сервер, затем подключитесь снова. |
| Сохранённый PIN недоступен | Введите PIN вручную и проверьте аутентификацию/настройки Windows. |
| Ошибка документа | Изучите ошибку, сохраните исходник и устраните причину перед повтором. |

После неверного PIN остановитесь и проверьте его, не пытайтесь угадывать. Сообщите версии приложения и Windows, редакцию MSI или Store, архитектуру, модель считывателя и шаги воспроизведения. См. [устранение неполадок](/docs/troubleshooting).

## Подтверждайте локальные запросы подписи (MCP)

В **Настройки → Общие** прокрутите до **Дополнительно** и включите **Разрешить локальные запросы подписи (MCP)**. Скопируйте частную папку под переключателем в конфигурацию клиента MCP. Оставьте eSemnBun запущенным и выберите нужную карту. В демонстрационном режиме эта настройка недоступна.

```powershell
& "C:\Program Files\eSemnBun\bin\esemnbun.exe" mcp `
  --root "documents=C:\Users\me\Documents\Signing" `
  --broker-directory "C:\Users\me\AppData\Local\MoldSign\MCP"
```

Используйте папку, показанную вашей установкой, вместо примера ниже. Клиент может подготовить PDF через `prepare_signing`, проверить состояние через `get_job` или отменить запрос через `cancel_job`. Изучите PDF в окне предварительного просмотра и выберите «Подписать», только если согласны; затем следует авторизация картой. Сохранённый PIN не отменяет подтверждение. Отмена или тайм-аут не доказывают, что подпись не была создана.

Снимок сделан с изолированным демонстрационным профилем: путь служит примером, а переключатель MCP недоступен. Запросы подписи MCP при съёмке не выполнялись.

## Зашифруйте файл паролем

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Карта не нужна. Создайте пароль для файла и передайте получателю по отдельному доверенному каналу. Это не PIN карты. Шифрование создаёт отдельный файл; сохраните оригинал до проверки результата.

## Зашифруйте для владельца сертификата

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Попросите у получателя открытый сертификат шифрования (.cer/.der), экспортированный по следующему руководству. Подтвердите отпечаток с владельцем по доверенному каналу. Сертификата только для подписи недостаточно. Для шифрования нужен открытый сертификат, а не карта, закрытый ключ или PIN получателя.

## Расшифруйте полученный файл

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Уточните у отправителя метод. Для файла с паролем получите пароль отдельно. Для файла с сертификатом подключите соответствующую поддерживаемую карту и считыватель; нужны ключ шифрования и PIN. Другая карта или карта только для подписи не подойдёт.

<GuideScreenshot src="/img/guide/windows/ru/protect-decrypt-light.png" alt="Расшифруйте полученный файл" steps={[{"x": 40, "y": 25, "text": "Выберите Расшифровать и полученный зашифрованный файл."}, {"x": 40, "y": 60, "text": "Выберите Пароль и введите пароль от отправителя."}, {"x": 40, "y": 88, "text": "Нажмите Расшифровать и сохраните результат под новым именем."}]} />

Для расшифровки картой выберите Сертификат/карта, затем чтение карты. Выберите нужную идентичность шифрования, проверьте сведения, введите PIN и нажмите Расшифровать. Сохраните под новым именем. Если подходящей идентичности нет, запросите копию с паролем. После ошибки PIN остановитесь; не повторяйте автоматически.

Откройте и проверьте сохранённый результат. Совместимое с MoldSign шифрование не удостоверяет содержимое: успешная расшифровка сама по себе не доказывает целостность или правильность пароля.


## Поделитесь сертификатом шифрования

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Подключите поддерживаемую карту и USB-считыватель. Для экспорта открытого сертификата не нужны документ или PIN. Карта должна предоставлять идентичность шифрования; обычный сертификат подписи её не заменяет.

После чтения выберите нужную идентичность и раскройте сведения о сертификате. Экспортируйте сертификат шифрования, сохраните .cer и передайте отправителю. Отдельно сравните отпечаток. Экспортируется только открытый сертификат; закрытый ключ остаётся на карте. На снимке показан начальный экран до чтения.


## Удалите локальный файл

Откройте Документы → Защита файлов. Выберите доступный файл; при необходимости прокрутите форму. Руководства описывают новую функцию, которая может ещё отсутствовать в установленной версии из магазина.

Только на компьютере. После подтверждения безвозвратно удаляется один поддерживаемый обычный локальный файл. Стирание с SSD, снимков, резервных и других копий не гарантируется. Неподдерживаемые расположения и ссылки отклоняются. Мобильные поставщики документов не поддерживают операцию.
