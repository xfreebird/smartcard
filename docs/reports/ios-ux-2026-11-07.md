# iOS and iPadOS UX review — 2026-11-07

The signing workspace now uses two columns from 560 points of usable window width. The original 760-point cutoff excluded smaller landscape phones; the Duo follow-up also accounts for vertical system bars and expanded portrait windows. Sign uses an inline title, with the action in the native toolbar for compact-height layouts and beside the card otherwise. Accessibility Dynamic Type sizes use one scrollable column. In narrower single-column regular-width windows, the identity card is centered and capped at 400 points.

The initial representative captures below precede the later Duo header/threshold changes. Final native Duo captures, SDK 27.1 build and standard-phone smoke are recorded in [the Duo follow-up](iphone-duo-ux-2026-11-07.md). ## Limits

This is representative simulator visual coverage, not every iPhone/iPad size or OS version. Large iPads, iPad multitasking/window resizing, accessibility text in landscape, VoiceOver, English/Russian runtime rendering, actual Files picker/drag-and-drop, mixed signing batches, verification result disclosures, share actions, cold-launch splash and physical reader signing were not exercised in this round. Landscape accessibility fallback and native signing Label semantics were checked in source only. File screenshots and simulated cards do not prove reader integration or signing correctness. The separate full Swift core suite passed 63 tests with 5 opt-in skips and 0 failures.

The first optional portrait Verify capture timed out after its simulator window closed. A later CLI-only run captured portrait Verify and the largest accessibility text size in both themes. That accessibility run found the compact filename squeezed between size/menu controls; a dedicated stacked row fixes it, and the final iOS Debug rebuild and screenshots passed. A subsequent final compile after the shared filesystem-helper addition also passed (`/tmp/esemnbun-ios-final-build.log`); final core count is 63 tests, 5 opt-in skips, 0 failures. The phone's text size was restored to its original `large`, its appearance retained dark, and it was shut down. The iPad remains shut down with light appearance.
