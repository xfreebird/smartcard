eSemnBun CLI packages

Signing, verification and local MCP tools. Installing a package does not start a service or enable unattended signing.

macOS — Apple silicon and Intel, macOS 15+

brew install xfreebird/utils/esemnbun-cli

Windows x64 — Scoop

scoop bucket add esemnbun https://github.com/xfreebird/homebrew-utils
scoop install esemnbun/esemnbun-cli

Windows x64 — Chocolatey

Download the esemnbun-cli.VERSION.nupkg package from the current release into an empty folder, then run from that folder:

choco install esemnbun-cli --source . --yes

This is a project-distributed package; it is not listed in the Chocolatey community catalog.

Ubuntu 24.04+ / Debian 13+ — x86-64

curl -fsSLo /tmp/esemnbun-signing-key.asc https://esemnbun.md/packages/signing-key.asc
gpg --show-keys --with-fingerprint /tmp/esemnbun-signing-key.asc

Verify fingerprint F807 5499 A4B3 11BA 30E5 3156 E562 2B86 C828 0D0B, then:

gpg --dearmor --yes --output /tmp/esemnbun.gpg /tmp/esemnbun-signing-key.asc
sudo install -m 644 /tmp/esemnbun.gpg /usr/share/keyrings/esemnbun.gpg
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/esemnbun.gpg] https://esemnbun.md/packages/apt stable main' | sudo tee /etc/apt/sources.list.d/esemnbun.list
sudo apt update
sudo apt install esemnbun-cli

Fedora — x86-64

The RPM carries its required library versions; DNF checks dependencies and signatures.

curl -fsSLo /tmp/esemnbun.repo https://esemnbun.md/packages/esemnbun.repo
sudo install -m 644 /tmp/esemnbun.repo /etc/yum.repos.d/esemnbun.repo
sudo dnf install esemnbun-cli

Verify the same signing fingerprint when prompted. Both package and repository signatures are required. The same RPM repository can be added to compatible openSUSE systems with Zypper; compatibility depends on available libraries.

Arch Linux — x86-64

Use the project PKGBUILD: download it, inspect it, then run makepkg -si. This recipe is not submitted to AUR.

Other Linux systems

A portable CLI tar archive is also available. It requires compatible glibc, OpenSSL, libcurl and PC/SC libraries; it is not a musl/Alpine build. Current Linux binary packages are x86-64.
